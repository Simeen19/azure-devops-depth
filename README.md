# Vedinc DevOps Website

A sleek, futuristic DevOps learning platform showcasing **Vedinc** and **Azure** with interactive 3D effects.

## Overview

This website is designed to teach DevOps concepts in an engaging way. It highlights **Vedinc** and **Azure** through a visually striking interface, including animated buttons and 3D effects, creating a modern and immersive user experience. The design follows a black and Azure-blue color palette for a professional and tech-forward look.

## Features

- **3D Interactive UI** using Three.js
- Animated **Azure** button with glowing effects
- **Vedinc Logo** displayed prominently
- Two main pages:
  - **Home** – Landing page with logo and interactive elements
  - **Contact** – Simple form for inquiries
- Responsive and visually engaging design
- Clean and futuristic black & blue color scheme

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React
- **Animations & 3D Effects:** Three.js
- **Package Management:** Node.js + npm
